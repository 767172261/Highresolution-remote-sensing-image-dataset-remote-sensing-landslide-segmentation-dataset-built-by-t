### **山区滑坡识别遥感影像数据集**

| **项目** | **详情** |
| :--- | :--- |
| **数据集名称** | 山区滑坡识别高分辨率遥感影像数据集 |
| **地理范围** | 中国西南地区多个典型滑坡易发区域 |
| **主要用途** | 滑坡区域检测、语义分割（像素级识别） |
| **图像总数** | 990 张（每张对应一个滑坡实例） |
| **空间分辨率** | 1 米 / 像素 |
| **图像尺寸** | 1000 × 1000 像素 |
| **图像格式** | RGB 三波段（真彩色） |
| **数据类型** | 高分辨率光学遥感影像 |
| **数据集大小** | 约 920 MB |
| **标注形式** | 滑坡区域边界掩膜（Mask），像素级二值标注（0: 非滑坡, 1: 滑坡） |
| **样本数量** | 990 个滑坡实例（每个图像标注一个主要滑坡区域） |
| **地貌类型** | 高山峡谷、高陡坡地、断层密集带、植被稀疏区、碎屑流区域等 |
| **诱发机制覆盖** | 强降雨、地震、地质构造活动等 |
| **地表特征** | 具有显著的地貌多样性与地形复杂性，包含裸露地表、部分植被覆盖、裂缝、滑坡后缘与堆积区等典型特征 |
| **适用任务** | - 滑坡目标检测（基于边界框）<br> - 滑坡语义分割（像素级分类）<br> - 变化检测（多时相扩展应用）<br> - 地质灾害自动识别模型训练 |
| **适用模型** | U-Net, DeepLabV3+, PSPNet, Mask R-CNN, YOLACT, SegFormer 等分割/检测模型 |
| **数据特点** | - 高空间分辨率，支持精细边界识别<br> - 地貌多样，泛化性强<br> - 标注精确，适用于自动化灾害监测系统开发 |

---

✅ **说明**：  
该数据集专为**山区滑坡智能识别与语义分割任务**构建，具有良好的地理代表性和灾害机制覆盖性，适用于训练深度学习模型实现遥感影像中滑坡区域的自动提取与边界划分，可广泛应用于地质灾害预警、灾后评估和智慧防灾系统。
